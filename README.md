# SPP — Snap Ping Pong

드래그로 스윙하는 인터랙티브 탁구 게임.

**▶ 바로 플레이: https://hooni9807.github.io/spp/**

### 한눈에 보기
- **AI 대전**: 동호회 부수 8단계(7부 ~ 선수부) × 난이도 6종 — 이지 · 하드 · 익스트림 · 울트라 · **울트라 하드**(쓰리터치) · **울트라 익스트림**(포터치)
- **보스전**: 👑 민희쌤 · 😈 탁구 마왕 · 👵 세종 9부 아줌마 · 🃏 사기부수 갓융자 (보스 클리어 랭킹)
- **복식 · 3인 대전**(육각형 탁구대) — AI 상대 또는 온라인으로 사람끼리
- **온라인**: 1:1 · 복식(4명) · 3인(3명) 방 만들기, 빠른 대전, 친구 목록 · 도전 · 채팅
- **연습장**: 연습 봇 · 커트맨 봇전 · 투클릭 · 쓰리터치 · 포터치 공 연습 · ♾️ 무한 드라이브
- **캐릭터 21명**(고유 특성 · PERFECT 대사), **레벨 · 캐릭터 해금**, **🌟 스킬트리**(30포인트, 캐릭터별 페이지), **퀘스트**, **🏅 칭호**(23개), **👕 아웃핏 스튜디오**(추천 코디 6세트 · 고인물 룩 4세트 · 상의 · 하의 · 모자 · 날개 · 펫 · 이펙트)
- **🎖️ 랭크전**: AI 상대 브론즈 → 챌린저 티어전
- **랭킹**: 랭크전 · PvP 레이팅 · AI전 승리 · 최고 랠리 · 무한 드라이브 · 보스 클리어(보스 종류 체크박스) · 레벨

로컬에서는 저장소의 파일을 함께 둔 뒤 `index.html`을 브라우저로 열면 게임이 실행됩니다. 로컬 서버로 확인하려면 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/`로 접속하세요. (빌드·패키지 설치 불필요)

## 코디 착용 보정

- 모자와 헤어밴드는 얼굴 이미지의 머리 윤곽과 움직임에 맞춥니다.
- 옷깃과 소매, 바지 주머니와 갑옷, 손목 장식이 몸과 관절을 따라가도록 조정했습니다.
- 망토와 목 장식의 겹침 순서를 고치고, 승리 댄스에도 장착한 코디를 적용했습니다.
