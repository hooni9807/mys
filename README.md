# SPIN LAB

드래그로 스윙하는 인터랙티브 탁구 게임.

**▶ 바로 플레이: https://hooni9807.github.io/spin-tt/**

로컬에서는 저장소의 파일을 함께 둔 뒤 `index.html`을 브라우저로 열면 게임이 실행됩니다. 세리머니 원본 음악까지 확인하려면 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/`로 접속하세요. (빌드·패키지 설치 불필요)

## 온라인 1:1 (친구와 대전)

1. 한 명이 시작 화면에서 **온라인 방 만들기** → 4자리 **방 코드**가 나옵니다.
2. 코드를 카톡 등으로 보내고, 친구는 같은 주소에서 **방 코드 입력 → 참가**.
3. 연결되면 바로 11점 경기 시작. 각자 화면에서 **내가 항상 아래쪽**에 보입니다.

- 로그인 · 설치 없음. 서브 교대, 필살기, 라켓 선택 모두 그대로 적용됩니다 (상대 라켓 · 필살기도 보임).
- 방장이 공과 점수를 계산하고, 참가자는 자기 스윙을 판정해 보냅니다.
- 온라인 중에는 일시정지 · 이어하기 · 모드 변경이 꺼집니다. 다시 하기는 방장이 누릅니다.
- 연결은 PeerJS(WebRTC)로 두 기기를 직접 잇습니다. 같은 와이파이나 일반 인터넷에서는 대부분 잘 되지만, **일부 회사망 · 이동통신망에서는 연결이 안 될 수 있습니다** (중계 서버를 따로 두면 해결 가능).

## 멀티플레이 승리 세리머니

- 11점 이상 · 2점 차로 경기가 끝나면 승자가 탁구대 위로 뛰어올라 **12초간 승리 춤**을 춥니다. 패자는 옆에서 바라보며, 두 화면 모두 같은 승자·춤·남은 시간을 표시합니다.
- [참고 영상](https://www.youtube.com/shorts/Q4EyleX7Qh4)의 팔 돌리기, 좌우 스텝, 어깨 흔들기와 가리키는 동작을 캐릭터용 절차적 애니메이션으로 재구성했습니다.
- 관람 중에는 스윙과 재경기가 잠깁니다. 끝나면 결과 화면에서 **방장만 재경기**를 시작할 수 있습니다. 방 나가기와 음소거는 계속 가능합니다.
- 방장이 경기 ID·승자·시작 시각을 전송합니다. 참가자는 시계 차이를 보정하며, 늦거나 중복된 패킷으로 춤이 재시작되거나 레이팅이 두 번 적용되지 않습니다. 백그라운드 복귀·연결 종료 시에도 정리됩니다.
- 원본 음악은 화면에 보이지 않는 **공식 YouTube 재생기**로 함께 재생합니다. `사운드 OFF`는 유지하며, 자동재생이 차단되면 **음악 재생 ♪**을 누르세요. 인터넷·YouTube 임베드 허용 상태에 따라 음악이 재생되지 않을 수 있지만 세리머니는 정상 종료됩니다. 오디오 파일을 추출하거나 저장하지 않습니다.
- 시작 화면의 **내 승리 세리머니 / 상대 승리 관람**으로 로그인·실제 경기·레이팅 변경 없이 춤과 음악을 미리 볼 수 있습니다.
- 호스트와 참가자 모두 최신 버전으로 새로고침한 뒤 접속하세요. 새 경기 ID/시계 동기화 프로토콜은 이전 버전과 호환되지 않습니다.

## 플레이 방법

- 공이 내 코트에 한 번 튄 뒤 **내 쪽 끝선 밖으로 나오면** 스윙합니다. 공 주위 **링이 라켓 크기 원에 딱 맞는 순간**이 PERFECT.
- 공 테두리 원: **WAIT**(흰색) → **READY**(금색) → **HIT!**(초록색) 순간에 스윙하면 PERFECT.
- 마우스 / 터치 모두 지원합니다.

| 조작 | 동작 |
|---|---|
| 공 오른쪽 아래 → 위로 드래그 | 드라이브 |
| 공 왼쪽 아래 → 위로 드래그 | 백드라이브 |
| 아래로 끊어 드래그 | 커트 |
| 짧고 가볍게 드래그 | 쇼트 |
| 한 번 탭 / 클릭 | **쇼트** |
| 상대가 띄운 **찬스볼**에 위·옆으로 드래그 | 자동 **스매시** · 드래그를 오른쪽으로 더 그으면 오른쪽, 왼쪽이면 왼쪽으로 |
| 상대 **쇼트(블록)** 에 아래로 긋기 | **커트**로 넘기기 · PERFECT면 낮고 깔끔하게, 아니면 공이 떠서 상대 찬스볼 |
| 상대 **드라이브**에 타이밍 맞춰 탭 | **블록(쇼트)** 으로 막기 |
| 라켓을 공보다 **낮게** 대고 기다리기 → 위로 긋기 | **드라이브** (낮게 기다리는 건 스매시가 아니라 드라이브 준비) |
| 필살기 게이지 100% 후 다음 타격 | 라켓별 필살기 (자동 발동) |
| 내 서브 차례: 탭으로 토스 → 떨어질 때 스윙 | 서브 (방향으로 회전 결정) |
| `Space` | 일시정지 |
| `처음 화면` | 현재 경기를 끝내고 라켓·난이도 설정으로 돌아가기 |




## 라켓 내리기 · 들기 (드라이브 / 커트 준비)

화면을 터치하는 순간 **라켓 위치**로 준비 자세가 정해지고, 캐릭터 자세와 라켓 옆 배지로 바로 보여요.

| 터치한 곳 (공이 맞을 자리 기준) | 준비 자세 | 그다음 |
|---|---|---|
| 라켓이 **아래** | 라켓을 낮게 내림 · **↑ 드라이브 준비** | 위로 그으면 **드라이브** · 짧게 아래로 빼는 건 백스윙으로 무시 |
| 라켓이 **위** | 라켓을 머리 옆으로 듦 · **↓ 커트 준비** | 아래로 그으면 **커트** · 짧게 위로 움직이는 건 무시 |
| 공 자리 바로 그 위치 | 보통 | 위로 = 드라이브, 아래로 = 커트 |

준비 자세와 반대 방향으로 바꾸고 싶으면 **길게(45px 이상) 확실히** 그어주세요.

- 손을 떼면 라켓이 약 0.3초 뒤 **허리 아래 준비 위치로 자동으로 내려와요** (다음 공을 드라이브로 받기 쉬운 자세).
- 터치한 채 **천천히 끄는 건 라켓을 옮기는 것**으로만 처리되고, 빠르게 휘두르기 시작한 지점에서 내리기 · 들기가 다시 정해져요.

## 타이밍 성공률

맞는 기술로 쳐도 타이밍에 따라 들어갈 확률이 달라요. 실패하면 네트나 아웃으로 나갑니다.

| 타이밍 | 들어갈 확률 |
|---|---|
| **PERFECT** (링이 라켓 크기 원에 딱 맞을 때) | 100% |
| **GOOD** (살짝 이르거나 조금 빗맞음) | 95% |
| **LATE** (많이 늦음 · 들어가도 찬스볼로 뜸) | 90% |
| 완전히 놓침 | 0% |

필살기는 타이밍과 상관없이 항상 들어가요. 쉐이크핸드 목판 · 러버의 컨트롤, 캐릭터 약점 실수는 이 확률을 통과한 뒤에 추가로 적용됩니다.


## 회전 · 속도의 영향

| | 받는 쪽에 미치는 영향 |
|---|---|
| **회전이 많을수록** | 받는 쪽이 놓칠 확률 ↑ (회전 0.6을 넘는 1.0마다 +6%p) · 예: 루프(회전 2.2) → 약 +10%, 이너+09C 루프(회전 4.2) → AI 리턴 85% → 65% |
| **공이 빠를수록** | PERFECT 구간이 짧아져 타이밍 맞추기가 어려움 (보통 3m/s 공 0.17초 → 5m/s 0.06초) · AI도 빠른 공을 덜 받음 |

나와 상대(AI · 온라인) 모두 같은 규칙이 적용됩니다.

## 코스 조절

아래에서 위로 그으면 드라이브, 그 스윙이 **어느 쪽으로 기울었는지**가 공의 코스가 됩니다 (커트도 같음).

| 스윙 | 공이 가는 곳 |
|---|---|
| 똑바로 위로 | 가운데 |
| 오른쪽으로 살짝 기울여 위로 (약 20°) | 오른쪽 |
| 오른쪽으로 크게 기울여 위로 (약 45°) | 오른쪽 코너 끝 |
| 왼쪽으로 살짝 / 크게 | 왼쪽 / 왼쪽 코너 끝 |

스윙의 가장 낮은 지점부터 끝까지의 전체 방향으로 판단하므로, 치는 순간 손가락이 조금 흔들려도 코스가 바뀌지 않아요.

## 기술 상성

상대 공의 종류는 세 군데에서 색으로 보입니다: 상대가 치는 순간 **상대 옆의 큰 배지**, 공의 **꼬리 색**(커트 파랑 · 드라이브 주황 · 스매시 빨강 · 찬스볼 노랑), 링 아래 **배지**. 공 위의 선이 도는 방향으로 상회전 · 하회전도 구분돼요. 맞는 기술로 받아야 넘어가고, 틀리면 네트에 걸리거나 테이블을 넘어갑니다.

| 들어온 공 | 넘어가는 기술 | 실패 |
|---|---|---|
| 커트 | 커트 · 드라이브 | 쇼트 · 스매시 → **네트에 걸림** |
| 드라이브 | 블록(탭) · 드라이브 | 커트 · 스매시 · 쇼트 → **테이블을 넘어감** (수비수는 **PERFECT 커트**면 OK) |
| 스매시 | **PERFECT 타이밍**의 쇼트 · 블록 (수비수는 PERFECT 커트도) | 그 외 → **테이블을 넘어감** |
| 막은 공 (블록) | 무엇이든 OK · **스매시 찬스** | — |

- 필살기는 상성과 관계없이 항상 넘어갑니다.
- 상대 AI도 드라이브 · 커트 · 스매시를 섞어 보냅니다 (낮은 공은 스매시하지 않음).
- 내가 드라이브를 치면 AI가 약 30% 확률로 **막아서(블록)** 느리고 높게 뜬 공을 보냅니다. 이 뜬 공에 **스윙하면 자동 스매시**로 끝낼 수 있어요.
- AI 서브도 내 서브처럼 **자기 코트에 한 번 튀긴 뒤** 내 코트로 넘어옵니다.
- **찬스볼**: 타이밍이 늦으면(LATE) 공이 높고 느리게 떠서 상대에게 찬스볼이 됩니다. AI는 찬스볼을 대부분 **강타(⚡⚡)** 하고, 강타는 PERFECT 타이밍의 쇼트 · 블록으로만, 더 좁은 범위에서 막을 수 있어요. 반대로 AI가 막아서 띄운 공을 내가 스매시하면 강타가 되어 AI도 거의 못 받습니다.

## 서브

- 실제 탁구처럼 **2점마다 서브권이 바뀝니다** (10:10 듀스부터는 1점마다). 첫 서브는 AI.
- 내 차례가 되면 **공을 손에 들고** 있습니다. 화면을 누르면 **토스**, 공이 떨어질 때(초록 **HIT!**) 스윙하면 서브가 나갑니다.
  - 공은 탁구대보다 높은 곳에서만 칠 수 있습니다 (실제 규칙). 놓치면 다시 토스하면 됩니다.
- 스윙 방향에 따라 회전과 코스가 정해집니다.

| 스윙 방향 | 결과 |
|---|---|
| 위 → 아래 | 하회전 (커트) |
| 아래 → 위 | 상회전 |
| 왼쪽 ↔ 오른쪽 | 회전 없음, 그 방향 코스로 |

- 스윙이 빠를수록 빠른 서브가 됩니다. 궤적은 항상 내 코트에 한 번 튄 뒤 네트를 낮게 넘어 상대 코트에 들어가도록 자동 계산됩니다 (너무 빠르면 자동으로 속도를 줄임).

## 코스 (좌우 방향)

- **오른쪽 → 왼쪽으로 휘두르면 공이 왼쪽**, **왼쪽 → 오른쪽으로 휘두르면 오른쪽**으로 갑니다.
- 위아래로만 휘두르면 가운데 쪽으로 갑니다. 서브와 필살기도 같은 규칙을 따릅니다 (스매시는 직선).

## 포핸드 / 백핸드

- 공 **오른쪽**에서 스윙 → 라켓이 몸 오른쪽, **검정 러버** (포핸드)
- 공 **왼쪽**에서 스윙 → 라켓이 몸 왼쪽, **빨강 러버** (백핸드)

## 라켓 선택

설정 카드의 **내 라켓**에서 고를 수 있습니다. 선택한 라켓·난이도·사운드·최고 랠리는 브라우저에 저장됩니다.

| 라켓 | 특징 | 타격 범위 | 파워 | 특기 |
|---|---|---|---|---|
| 쉐이크핸드 | 균형형, 비스카리아 외형 (거의 둥근 157×150mm 헤드, 플레어 손잡이, 5겹 나무 + 2겹 카본) | 1.0 | 1.0 | **백핸드 드라이브**: 백핸드 쪽 드라이브 계열 속도 ×1.25 |
| 중국식 펜홀더 | 짧은 손잡이, 빠른 손목 | 0.95 | 1.08 | **빠른 쇼트**: 쇼트 속도 ×1.5 |
| 일본식 펜홀더 | 네모난 헤드, 코르크 손잡이 | 0.9 | 1.18 | **포핸드 강타**: 포핸드 드라이브 속도 ×1.25 |
| 수비수 라켓 | 크고 넓은 면, 포핸드(검정) 민러버 + 백핸드(빨강) **롱핌플**(오돌토돌한 이질러버, 스펀지 없는 OX) | 1.2 | 0.85 | **수비 특화**: 스윙은 강한 커트(CHOP) · 드라이브 · 스매시는 **PERFECT 커트**로만 방어 (PERFECT 범위 65%로 좁음) · 뜬 공(찬스볼)은 **스윙하면 자동 스매시** · 탭 쇼트 가능 |

### 라켓별 필살기

게이지가 100%가 되면 다음 타격에 자동으로 발동합니다.

| 라켓 | 필살기 | 효과 | 꼬리 색 |
|---|---|---|---|
| 쉐이크핸드 | **초승달 드라이브** | 강한 옆회전으로 바깥쪽으로 빠지는 듯하다가 크게(약 45cm) 휘어 반대쪽 코너에 꽂히는 드라이브 | 분홍 |
| 중국식 펜홀더 | **번개 속공** | 네트를 낮게 스치며 같은 쪽 코너로 꽂히는 초고속 직선 | 하늘 |

## 저장 / 이어하기

- 점수가 날 때마다 **점수 · 모드 · 필살기 게이지**가 브라우저에 자동 저장됩니다.
- 창을 닫았다 다시 열면 시작 화면에 **이어하기 (7 : 5 · 11점 경기)** 버튼이 나오고, 누르면 다음 서브부터 이어집니다.
- **플레이 시작**(새 게임)을 누르거나 11점 경기가 끝나면 저장이 지워집니다.
- 같은 기기 · 같은 브라우저에서만 이어할 수 있고, 시크릿 창이나 사이트 데이터 삭제 시 사라집니다.

## 캐릭터 모션

기술마다 **백스윙 → 임팩트 → 마무리** 3단계 동작과 체중 이동이 나오고, 공을 치면 코치 노트에 그 기술의 자세 요령이 표시되어 따라 할 수 있습니다.

| 기술 | ① 백스윙 | ② 임팩트 | ③ 마무리 |
|---|---|---|---|
| 루프 드라이브 | 무릎 굽히고 라켓을 공보다 낮게, 체중은 오른발 | 골반을 돌리며 공 뒤를 위로 쓸기 | 라켓은 이마 앞까지, 체중은 왼발로 |
| 드라이브 | 허리 높이로 라켓을 뒤로 | 몸통을 돌리며 앞으로 밀어치기 | 눈높이에서 마무리 |
| 백드라이브 | 라켓을 배 앞으로, 팔꿈치는 앞으로 | 팔꿈치를 축으로 앞·위로 튕기기 | 눈높이 앞에서 멈추기 |
| 쇼트 | 몸 앞에서 짧게 | 공이 튀어 오를 때 밀기 | 바로 준비 자세로 |
| 커트 | 라켓을 가슴 쪽으로, 면을 열기 | 앞·아래로 공 밑을 깎기 | 팔을 거의 편 채 치는 방향으로 |
| 수비 커트 | 어깨 높이까지 들기 | 위에서 아래로 길게 깎기 | 무릎 높이까지, 자세는 낮게 |
| 스매시 | 어깨 뒤로 크게 | 높은 타점에서 몸 전체로 | 몸 앞을 가로질러 |
| 치키타 | 손목을 안쪽으로 감기 | 공 옆을 감아 올리며 손목 펴기 | 바깥 위로 높게 |

- 공이 오면 무릎을 굽힌 준비 자세를 잡습니다.

### 풋워크 (좌우 이동)

발이 한 걸음씩 땅을 딛고 움직이며, 남은 거리에 따라 스텝이 바뀝니다 (멀리 → 교차스텝 → 사이드스텝 → 원스텝).

| 스텝 | 언제 | 발 순서 (오른쪽으로 갈 때) |
|---|---|---|
| 원스텝 | 아주 가까울 때 | 오른발만 옆으로 내딛고, 왼발은 따라옴 |
| 사이드스텝 (샤세) | 중간 거리 | **왼발이 먼저** 오른발 쪽으로 붙고 → 오른발이 벌려 나감. 발은 교차하지 않음 |
| 교차스텝 | 멀리 | 왼발이 오른발 앞을 **가로질러** 넓게 → 오른발이 다시 나감 |

왼쪽으로 갈 때는 좌우를 반대로 합니다. 참고: [All About Table Tennis – Footwork](https://www.allabouttabletennis.com/table-tennis-footwork.html), [ActiveSG – Proper footwork](https://www.activesgcircle.gov.sg/learn/table-tennis/what-is-the-proper-footwork-for-table-tennis), [Modern Cross-step](https://protabletennis.net/content/modern-cross-step)
- 참고: [Critical Features of the Forehand Topspin](https://protabletennis.net/content/critical-features-forehand-topspin), [How to Play a Backhand Push](https://www.experttabletennis.com/how-to-play-a-backhand-push-in-table-tennis/), [Backhand Push (tabletennisteacher)](https://tabletennisteacher.com/learn-backhand-push/)

| 공 | 모양 | 공 속도 | 회전량 | 공 길이 |
|---|---|---|---|---|
| 나비 공 | 흰 공 · 빨간 점 | −10% | +10% | −10% |
| 액션 공 | 흰 공 · 파란 점 | +10% | −10% | +10% |
| 코늴리리아 공 | 주황 공 | ±0% | ±0% | ±0% |

- **공 속도**: 공이 날아가는 시간 자체가 빨라지거나 느려져요
- **회전량**: 공에 걸린 회전이 휘어지는 정도와, 받는 쪽이 회전 때문에 실수할 확률에 반영돼요
- **공 길이**: 칠 수 있는 PERFECT 구간의 길이 — 짧아지면 **타이밍 링(라켓 크기 원)도 작아져요**
- 온라인 대전은 양쪽이 같아야 해서 항상 코늴리리아 탁구대 + 코늴리리아 공

## 복식 (AI)

설정의 모드에서 **복식**을 고르면 **나 + AI 파트너 vs AI 2명**으로 11점 경기를 해요.

- **번갈아 치기**: 우리 편은 나 → 파트너 → 나 … 순서로 쳐요. 파트너 차례에는 내 링 · 구분선이 사라지고 파트너 머리 위에 "파트너 차례"가 떠요. 파트너는 그 순간 PERFECT 타이밍에 AI 실력(선택한 난이도)대로 받아쳐요. 상대 편도 두 명이 번갈아 쳐요
- **대각선 서브**: 서브는 내 코트 오른쪽 절반 → 상대 코트 오른쪽 절반(화면에서 왼쪽)으로만 들어가요. 서브 방향은 자동으로 대각선이 되게 맞춰져요
- **서브 순서**: 서브권은 2점마다 바뀌고, 우리 편 서브가 돌아올 때마다 나 → 파트너가 번갈아 서브해요. 상대 서브를 받는 사람(나 / 파트너)도 번갈아 바뀌어요
- 쉬는 선수는 뒤쪽 옆으로 비켜 서고, 파트너가 칠 때는 내 캐릭터도 옆으로 자리를 비켜줘요
- 파트너와 두 번째 상대는 나와 다른 캐릭터 중에서 정해져요

### 보스전 · 탁구 마왕 😈

- 모드에서 **보스전**을 고르면 상대로만 나오는 보스 **탁구 마왕**과 11점 경기를 해요 (내 캐릭터로는 고를 수 없어요)
- 뿔 · 빨갛게 빛나는 눈 · 붉은 망토 · 어두운 오라, 다른 캐릭터보다 덩치가 커요. 선수부보다 강하고 회전 서브를 넣어요
- 마왕의 기술 (받아칠 때 15% 확률로 하나)
  - **지옥불 스매시 🔥**: 화면이 흔들리는 강타. PERFECT 쇼트로만 막을 수 있어요
  - **암흑 회전 🌀**: 회전 ×1.8
  - **그림자 공 👻**: 공이 날아오는 중간에 사라져요. 바닥 그림자를 보고 치세요
- **2페이즈 (분노)**: 내가 6점을 따면 마왕이 분노해요. 오라가 주황색으로 바뀌고, 모든 공이 10% 빨라지고, 기술을 두 배(30%)로 써요
- 마왕을 이기면 랭킹의 **보스 클리어** 탭에 올라가요. 점수 차가 클수록 위, 같으면 그 경기 최고 랠리가 긴 순서 (보스전 승리는 'AI전 승리'에는 안 들어가요)

### 네이버 로그인

> ⏸ 현재 잠시 꺼둔 상태예요 (버튼 숨김). 네이버 검수가 끝나면 다시 켜요.

- 시작 화면의 **N 네이버로 로그인** (초록 버튼) → 네이버 동의 화면 → 게임으로 돌아오면 로그인 완료. 기록 · 설정 · 랭킹은 구글 로그인과 똑같이 저장돼요
- Firebase에는 네이버 로그인이 없어서, 무료 **Cloudflare Worker**(`naver-worker.js`)가 네이버 인증 코드를 Firebase 로그인 토큰으로 바꿔줘요. 네이버 Client Secret과 Firebase 서비스 계정 키는 Cloudflare 비밀 변수에만 있고 게임 코드 · 저장소에는 없어요
- 네이버로 로그인하면 구글 계정과는 별개의 계정이에요
- 네이버 앱이 "개발 중" 상태인 동안은 네이버 개발자센터에 등록한 테스트 계정만 로그인할 수 있어요 (모두 쓰려면 검수 요청)

## 랭킹

### PvP 랭킹전 (온라인 1:1)

- 온라인 방 만들기 / 참가 전에 **닉네임** 입력 → 경기가 끝나면 양쪽 레이팅이 자동으로 바뀝니다 (연결이 끊긴 경기는 반영 안 됨)
- **1000점 시작 · 이기면 +10, 지면 −10**, 연승/연패가 이어질 때마다 1점씩 더 (2연승 +11, 3연승 +12 … / 2연패 −11, 3연패 −12 …)
- 페이지 아래 **🏆 랭킹 → PvP 레이팅** 탭에 순위 표시

### AI전 기록

- 11점 경기(AI 상대)가 끝나면 닉네임으로 **최고 랠리** · **AI전 승리 점수**(난이도 단계 × 10 + 점수 차 · 7부 = 1단계 … 선수부 = 8단계) 등록
- 모두가 보는 **전체 랭킹**(상위 20, Firebase) · 연결이 안 될 때는 **내 기기 기록**

### 구글 로그인 (선택)

- 시작 화면의 **Google로 로그인** 버튼으로 로그인할 수 있어요. 로그인하지 않아도 모든 기능을 그대로 쓸 수 있습니다.
- 로그인하면 **랭킹전(PvP) 레이팅이 구글 계정에 묶여** 핸드폰 · PC 어디서든 이어집니다. 이미 이 기기에서 쌓은 레이팅은 로그인할 때 그대로 옮겨져요.
- 랭킹에는 닉네임과 내부 ID만 저장되고 **이메일은 저장하지 않아요**. 닉네임이 비어 있으면 구글 이름으로 채워집니다(수정 가능).
- 카카오톡 · 인스타그램 등 **앱 안 브라우저에서는 구글이 로그인을 막아서**, 카카오톡에서는 버튼을 누르면 외부 브라우저로 열립니다. 다른 앱에서는 ⋮ → 다른 브라우저로 열기를 이용하세요.

### 전체 랭킹 켜기 (Firebase)

공식 사이트는 이미 연결돼 있습니다(프로젝트 `spin-lab-ea7df`). 저장소를 복제해 내 서버로 쓸 때만 아래 순서를 따르세요.

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트 만들기 (Google 애널리틱스는 꺼도 됨)
2. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
3. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명**과 **Google** 사용 설정, **설정 → 승인된 도메인**에 사이트 주소(예: `내아이디.github.io`) 추가
4. Firestore **규칙** 탭에 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣고 **게시**
5. **프로젝트 설정(⚙️) → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 `index.html`의 `const FIREBASE_CONFIG=...` 자리에 넣기
6. 저장소에 올리면 1~2분 뒤 사이트에서 전체 랭킹이 보입니다

`firebaseConfig`는 공개돼도 되는 값입니다. AI전 기록은 **읽기와 추가만**, PvP 레이팅은 **자기 기기의 기록만** 규칙대로 정확한 점수 변화(±10, 연승/연패 보너스)로, 90초에 한 번만 바뀔 수 있습니다. 점수는 브라우저에서 계산되므로 조작을 완전히 막을 수는 없습니다.

## 모드

- **연습 랠리**: 리턴이 쉬워집니다.
- **11점 경기**: 11점 · 2점 차로 승리.

## 쉐이크핸드 목판 · 러버

설정에서 쉐이크핸드를 고르면 **목판**과 **러버**를 따로 고를 수 있어요. 두 값이 곱해져 드라이브 · 커트 · 스매시에 적용됩니다 (쇼트 · 블록 제외). 실수 확률 = 제대로 쳐도 네트 · 아웃이 날 확률.

| 목판 | 속도 | 회전 | 컨트롤 |
|---|---|---|---|
| 합판 | ×0.9 | ×0.9 | 좋음 (실수 −4%) |
| 이너 카본 | ×0.92 | **×1.35** | 보통 (+2%) |
| 아우터 카본 | **×1.25** | ×1.0 | 어려움 (+10%) |

| 러버 | 속도 | 회전 | 컨트롤 |
|---|---|---|---|
| 09C | ×0.9 | **×1.4** | 보통 (+3%) |
| 05 | **×1.25** | ×1.0 | 어려움 (+10%) |
| 64 | ×1.0 | ×1.0 | 좋음 (−2%) |
| SP 숏핌플 | ×1.3 | ×0.6 | 어려움 (+10%) · 상대 드라이브 25% 날아감 · 상대 커트 25% 붕 뜸 |

- 빠르거나 회전이 많은 공일수록 상대가 받기 어려워요 (예: 이너 + 09C → AI 리턴 약 47%, 합판 + 64 → 약 79%).
- 기본값은 합판 + 64. 선택은 저장됩니다.
