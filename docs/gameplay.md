# 🎮 플레이 방법

스윙 · 타이밍 · 회전 · 서브 · 라켓과 장비까지, 게임을 하는 방법을 모았어요.

[← README로 돌아가기](../README.md)

## 플레이 방법

- 공이 내 코트에 한 번 튄 뒤 **내 쪽 끝선 밖으로 나오면** 스윙합니다. 공 주위 **링이 라켓 크기 원에 딱 맞는 순간**이 PERFECT.
- 공 테두리 원: **WAIT**(흰색) → **READY**(금색) → **HIT!**(초록색) 순간에 스윙하면 PERFECT.
- 마우스 / 터치 모두 지원합니다.

| 조작 | 동작 |
|---|---|
| 공 오른쪽 아래 → 위로 드래그 | 드라이브 |
| 공 왼쪽 아래 → 위로 드래그 | 백드라이브 |
| 아래로 끊어 드래그 | 커트 |
| 짧고 가볍게 드래그 | 쇼트 |
| 한 번 탭 / 클릭 | **쇼트** |
| 상대가 띄운 **찬스볼**에 위·옆으로 드래그 | 자동 **스매시** · 드래그를 오른쪽으로 더 그으면 오른쪽, 왼쪽이면 왼쪽으로 |
| 상대 **쇼트(블록)** 에 아래로 긋기 | **커트**로 넘기기 · PERFECT면 낮고 깔끔하게, 아니면 공이 떠서 상대 찬스볼 |
| 상대 **드라이브**에 타이밍 맞춰 탭 | **블록(쇼트)** 으로 막기 |
| 라켓을 공보다 **낮게** 대고 기다리기 → 위로 긋기 | **드라이브** (낮게 기다리는 건 스매시가 아니라 드라이브 준비) |
| 필살기 게이지 100% 후 다음 타격 | 라켓별 필살기 (자동 발동) |
| 내 서브 차례: 탭으로 토스 → 떨어질 때 스윙 | 서브 (방향으로 회전 결정) |
| `Space` | 일시정지 |
| `처음 화면` | 현재 경기를 끝내고 라켓·난이도 설정으로 돌아가기 |

## 라켓 내리기 · 들기 (드라이브 / 커트 준비)

화면을 터치하는 순간 **라켓 위치**로 준비 자세가 정해지고, 캐릭터 자세와 라켓 옆 배지로 바로 보여요.

| 터치한 곳 (공이 맞을 자리 기준) | 준비 자세 | 그다음 |
|---|---|---|
| 라켓이 **아래** | 라켓을 낮게 내림 · **↑ 드라이브 준비** | 위로 그으면 **드라이브** · 짧게 아래로 빼는 건 백스윙으로 무시 |
| 라켓이 **위** | 라켓을 머리 옆으로 듦 · **↓ 커트 준비** | 아래로 그으면 **커트** · 짧게 위로 움직이는 건 무시 |
| 공 자리 바로 그 위치 | 보통 | 위로 = 드라이브, 아래로 = 커트 |

준비 자세와 반대 방향으로 바꾸고 싶으면 **길게(45px 이상) 확실히** 그어주세요.

- 손을 떼면 라켓이 약 0.3초 뒤 **허리 아래 준비 위치로 자동으로 내려와요** (다음 공을 드라이브로 받기 쉬운 자세).
- 터치한 채 **천천히 끄는 건 라켓을 옮기는 것**으로만 처리되고, 빠르게 휘두르기 시작한 지점에서 내리기 · 들기가 다시 정해져요.

## 타이밍 성공률

맞는 기술로 쳐도 타이밍에 따라 들어갈 확률이 달라요. 실패하면 네트나 아웃으로 나갑니다.

| 타이밍 | 들어갈 확률 |
|---|---|
| **PERFECT** (링이 라켓 크기 원에 딱 맞을 때) | 100% |
| **GOOD** (살짝 이르거나 조금 빗맞음) | 95% |
| **LATE** (많이 늦음 · 들어가도 찬스볼로 뜸) | 90% |
| 완전히 놓침 | 0% |

필살기는 타이밍과 상관없이 항상 들어가요. 쉐이크핸드 목판 · 러버의 컨트롤, 캐릭터 약점 실수는 이 확률을 통과한 뒤에 추가로 적용됩니다.

## 회전 · 속도의 영향

| | 받는 쪽에 미치는 영향 |
|---|---|
| **회전이 많을수록** | 받는 쪽이 놓칠 확률 ↑ (회전 0.6을 넘는 1.0마다 +6%p) · 예: 루프(회전 2.2) → 약 +10%, 이너+09C 루프(회전 4.2) → AI 리턴 85% → 65% |
| **공이 빠를수록** | PERFECT 구간이 짧아져 타이밍 맞추기가 어려움 (보통 3m/s 공 0.17초 → 5m/s 0.06초) · AI도 빠른 공을 덜 받음 |

나와 상대(AI · 온라인) 모두 같은 규칙이 적용됩니다.

## 코스 조절

아래에서 위로 그으면 드라이브, 그 스윙이 **어느 쪽으로 기울었는지**가 공의 코스가 됩니다 (커트도 같음).

| 스윙 | 공이 가는 곳 |
|---|---|
| 똑바로 위로 | 가운데 |
| 오른쪽으로 살짝 기울여 위로 (약 20°) | 오른쪽 |
| 오른쪽으로 크게 기울여 위로 (약 45°) | 오른쪽 코너 끝 |
| 왼쪽으로 살짝 / 크게 | 왼쪽 / 왼쪽 코너 끝 |

스윙의 가장 낮은 지점부터 끝까지의 전체 방향으로 판단하므로, 치는 순간 손가락이 조금 흔들려도 코스가 바뀌지 않아요.

## 기술 상성

상대 공의 종류는 세 군데에서 색으로 보입니다: 상대가 치는 순간 **상대 옆의 큰 배지**, 공의 **꼬리 색**(커트 파랑 · 드라이브 주황 · 스매시 빨강 · 찬스볼 노랑), 링 아래 **배지**. 공 위의 선이 도는 방향으로 상회전 · 하회전도 구분돼요. 맞는 기술로 받아야 넘어가고, 틀리면 네트에 걸리거나 테이블을 넘어갑니다.

| 들어온 공 | 넘어가는 기술 | 실패 |
|---|---|---|
| 커트 | 커트 · 드라이브 | 쇼트 · 스매시 → **네트에 걸림** |
| 드라이브 | 블록(탭) · 드라이브 | 커트 · 스매시 · 쇼트 → **테이블을 넘어감** (수비수는 **PERFECT 커트**면 OK) |
| 스매시 | **PERFECT 타이밍**의 쇼트 · 블록 (수비수는 PERFECT 커트도) | 그 외 → **테이블을 넘어감** |
| 막은 공 (블록) | 무엇이든 OK · **스매시 찬스** | — |

- 필살기는 상성과 관계없이 항상 넘어갑니다.
- 상대 AI도 드라이브 · 커트 · 스매시를 섞어 보냅니다 (낮은 공은 스매시하지 않음).
- 내가 드라이브를 치면 AI가 약 30% 확률로 **막아서(블록)** 느리고 높게 뜬 공을 보냅니다. 이 뜬 공에 **스윙하면 자동 스매시**로 끝낼 수 있어요.
- AI 서브도 내 서브처럼 **자기 코트에 한 번 튀긴 뒤** 내 코트로 넘어옵니다.
- **찬스볼**: 타이밍이 늦으면(LATE) 공이 높고 느리게 떠서 상대에게 찬스볼이 됩니다. AI는 찬스볼을 대부분 **강타(⚡⚡)** 하고, 강타는 PERFECT 타이밍의 쇼트 · 블록으로만, 더 좁은 범위에서 막을 수 있어요. 반대로 AI가 막아서 띄운 공을 내가 스매시하면 강타가 되어 AI도 거의 못 받습니다.

## 서브

- 실제 탁구처럼 **2점마다 서브권이 바뀝니다** (10:10 듀스부터는 1점마다). 첫 서브는 AI.
- 내 차례가 되면 **공을 손에 들고** 있습니다. 화면을 누르면 **토스**, 공이 떨어질 때(초록 **HIT!**) 스윙하면 서브가 나갑니다.
  - 공은 탁구대보다 높은 곳에서만 칠 수 있습니다 (실제 규칙). 놓치면 다시 토스하면 됩니다.
- 스윙 방향에 따라 회전과 코스가 정해집니다.

| 스윙 방향 | 결과 |
|---|---|
| 위 → 아래 | 하회전 (커트) |
| 아래 → 위 | 상회전 |
| 왼쪽 ↔ 오른쪽 | 회전 없음, 그 방향 코스로 |

- 스윙이 빠를수록 빠른 서브가 됩니다. 궤적은 항상 내 코트에 한 번 튄 뒤 네트를 낮게 넘어 상대 코트에 들어가도록 자동 계산됩니다 (너무 빠르면 자동으로 속도를 줄임).

## 코스 (좌우 방향)

- **오른쪽 → 왼쪽으로 휘두르면 공이 왼쪽**, **왼쪽 → 오른쪽으로 휘두르면 오른쪽**으로 갑니다.
- 위아래로만 휘두르면 가운데 쪽으로 갑니다. 서브와 필살기도 같은 규칙을 따릅니다 (스매시는 직선).

## 포핸드 / 백핸드

- 공 **오른쪽**에서 스윙 → 라켓이 몸 오른쪽, **검정 러버** (포핸드)
- 공 **왼쪽**에서 스윙 → 라켓이 몸 왼쪽, **빨강 러버** (백핸드)

## 라켓 선택

설정 카드의 **내 라켓**에서 고를 수 있습니다. 선택한 라켓·난이도·사운드·최고 랠리는 브라우저에 저장됩니다.

| 라켓 | 특징 | 타격 범위 | 파워 | 특기 |
|---|---|---|---|---|
| 쉐이크핸드 | 균형형, 비스카리아 외형 (거의 둥근 157×150mm 헤드, 플레어 손잡이, 5겹 나무 + 2겹 카본) | 1.0 | 1.0 | **백핸드 드라이브**: 백핸드 쪽 드라이브 계열 속도 ×1.25 |
| 중국식 펜홀더 | 짧은 손잡이, 빠른 손목 | 0.95 | 1.08 | **빠른 쇼트**: 쇼트 속도 ×1.5 |
| 일본식 펜홀더 | 네모난 헤드, 코르크 손잡이 | 0.9 | 1.18 | **포핸드 강타**: 포핸드 드라이브 속도 ×1.25 |
| 수비수 라켓 | 크고 넓은 면, 포핸드(검정) 민러버 + 백핸드(빨강) **롱핌플**(오돌토돌한 이질러버, 스펀지 없는 OX) | 1.2 | 0.85 | **수비 특화**: 스윙은 강한 커트(CHOP) · 드라이브 · 스매시는 **PERFECT 커트**로만 방어 (PERFECT 범위 65%로 좁음) · 뜬 공(찬스볼)은 **스윙하면 자동 스매시** · 탭 쇼트 가능 |

### 라켓별 필살기

게이지가 100%가 되면 다음 타격에 자동으로 발동합니다.

| 라켓 | 필살기 | 효과 | 꼬리 색 |
|---|---|---|---|
| 쉐이크핸드 | **초승달 드라이브** | 강한 옆회전으로 바깥쪽으로 빠지는 듯하다가 크게(약 45cm) 휘어 반대쪽 코너에 꽂히는 드라이브 | 분홍 |
| 중국식 펜홀더 | **번개 속공** | 네트를 낮게 스치며 같은 쪽 코너로 꽂히는 초고속 직선 | 하늘 |
| 일본식 펜홀더 | **천둥 스매시** | 가장 빠른 일격, 상대 코트 끝 구석을 강타 | 노랑 |
| 수비수 라켓 | **유령 커트** | 둥실 떠서 네트 앞에 툭 떨어지는 초강력 하회전 | 보라 |

## 쉐이크핸드 목판 · 러버

설정에서 쉐이크핸드를 고르면 **목판**과 **러버**를 따로 고를 수 있어요. 두 값이 곱해져 드라이브 · 커트 · 스매시에 적용됩니다 (쇼트 · 블록 제외). 실수 확률 = 제대로 쳐도 네트 · 아웃이 날 확률.

| 목판 | 속도 | 회전 | 컨트롤 |
|---|---|---|---|
| 합판 | ×0.9 | ×0.9 | 좋음 (실수 −4%) |
| 이너 카본 | ×0.92 | **×1.35** | 보통 (+2%) |
| 아우터 카본 | **×1.25** | ×1.0 | 어려움 (+10%) |

| 러버 | 속도 | 회전 | 컨트롤 |
|---|---|---|---|
| 09C | ×0.9 | **×1.4** | 보통 (+3%) |
| 05 | **×1.25** | ×1.0 | 어려움 (+10%) |
| 64 | ×1.0 | ×1.0 | 좋음 (−2%) |
| SP 숏핌플 | ×1.3 | ×0.6 | 어려움 (+10%) · 상대 드라이브 25% 날아감 · 상대 커트 25% 붕 뜸 |

- 빠르거나 회전이 많은 공일수록 상대가 받기 어려워요 (예: 이너 + 09C → AI 리턴 약 47%, 합판 + 64 → 약 79%).
- 기본값은 합판 + 64. 선택은 저장됩니다.

## 탁구대 · 공 (매판 랜덤)

경기를 시작할 때마다 **탁구대 1개 + 공 1개**가 랜덤으로 정해지고, 첫 서브 전에 **"이번 판 장비 🎲"** 팝업으로 약 3초 보여줘요. 두 장비의 효과는 곱해져요.

| 탁구대 | 모양 | 공 속도 | 회전량 | 공 길이 |
|---|---|---|---|---|
| 나비 탁구대 | 파란 상판 | −20% | ±0% | −20% |
| 액션 탁구대 | 짙은 남색 상판 | +20% | −20% | ±0% |
| 코늴리리아 탁구대 | 초록 상판 | ±0% | ±0% | ±0% |

| 공 | 모양 | 공 속도 | 회전량 | 공 길이 |
|---|---|---|---|---|
| 나비 공 | 흰 공 · 빨간 점 | −10% | +10% | −10% |
| 액션 공 | 흰 공 · 파란 점 | +10% | −10% | +10% |
| 코늴리리아 공 | 주황 공 | ±0% | ±0% | ±0% |

- **공 속도**: 공이 날아가는 시간 자체가 빨라지거나 느려져요
- **회전량**: 공에 걸린 회전이 휘어지는 정도와, 받는 쪽이 회전 때문에 실수할 확률에 반영돼요
- **공 길이**: 칠 수 있는 PERFECT 구간의 길이 — 짧아지면 **타이밍 링(라켓 크기 원)도 작아져요**
- 온라인 대전은 양쪽이 같아야 해서 항상 코늴리리아 탁구대 + 코늴리리아 공

## 저장 / 이어하기

- 점수가 날 때마다 **점수 · 모드 · 필살기 게이지**가 브라우저에 자동 저장됩니다.
- 창을 닫았다 다시 열면 시작 화면에 **이어하기 (7 : 5 · 11점 경기)** 버튼이 나오고, 누르면 다음 서브부터 이어집니다.
- **플레이 시작**(새 게임)을 누르거나 11점 경기가 끝나면 저장이 지워집니다.
- 같은 기기 · 같은 브라우저에서만 이어할 수 있고, 시크릿 창이나 사이트 데이터 삭제 시 사라집니다.
