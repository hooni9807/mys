## 🌟 스킬트리

옛 리그 오브 레전드 특성(마스터리) 방식. **레벨마다 1포인트, 최대 30포인트**를 공격 · 방어 · 유틸 세 트리에 자유롭게 나눠 찍어요 (30/0/0, 21/9/0, 0/23/7 …).

- 공격 · 방어 · 유틸 **20개씩 (총 60개)** · 스킬마다 **1~2단계** — 30포인트로는 다 못 찍어서 고르는 재미. 트리에 4포인트를 쓸 때마다 다음 줄이 열리고, 맨 아래 **핵심 스킬**은 16포인트부터
- **1대1에서도 모든 스킬이 적용**돼요: "상대 리턴 확률 −%" 스킬은 사람 상대의 타구 실수 +%로, 필살기 게이지 스킬은 상대 게이지에, 행운 · 엣지 · 네트 행운은 두 화면이 같은 결과로
- **캐릭터마다 따로** 찍어요. 캐릭터를 고르면 그 캐릭터의 스킬 창이 바로 열리고, 시작 화면 🌟 스킬트리 버튼에서도 캐릭터를 바꿔 가며 보거나 찍을 수 있어요
- 초기화는 언제든 무료: 트리 이름 옆 **공격 / 방어 / 유틸 초기화**로 한 트리만, 아래 **전체 초기화**로 모두 · 진행 상황은 기기와 구글 계정에 저장

## 필살기 (20종)

필살기 게이지가 100%가 되면 다음 타격에서 **상대 공의 종류에 맞는 장착 필살기**가 자동으로 나가요. 맞는 게 없으면 "언제든" 필살기, 그것도 없으면 라켓 기본 필살기가 나가요.

- 메인 화면 **🌟 스킬트리 · 필살기** → 위쪽 탭으로 스킬트리 ↔ 필살기 전환
- 캐릭터 선택 → 스킬트리 → **필살기 선택 창**이 이어서 떠요
- 캐릭터마다 따로 저장 (재도전 · 다음 접속에도 그대로) · 슬롯: Lv1 1칸 · Lv10 2칸 · Lv20 3칸
- 발동하면 화면에 필살기 이름 배너와 필살기별 임펙트(번개 · 링 · 꽃잎 · 불꽃 · 운석 · 칼날 등)

| 발동 상황 | 필살기 |
|---|---|
| 상대 커트 | 용오름 루프 · 폭렬 드라이브 · 안개 커트 · 회오리 훅 |
| 상대 드라이브 | 카운터 블리츠 · 거울 반사 · 흡수 커트 · 역류 카운터 |
| 상대 짧은 공 | 바나나 플릭 · 스톱 드롭 · 장검 찌르기 |
| 상대 뜬 공 · 로빙 | 메테오 스매시 · 낙뢰 일격 · 불사조 스매시 |
| 상대 서브 | 선제 플릭 · 역습 리시브 |
| 상대 스매시 | 철벽 카운터 · 빛의 반격 |
| 언제든 | 혜성 드라이브 · 환영 페이크 |
